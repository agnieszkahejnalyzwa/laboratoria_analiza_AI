# Analiza matematyczna: zbiór zadań programistycznych w języku Python komplementarny do przedmiotu Analiza matematyczna dla kierunku Sztuczna Inteligencja w Analizie Danych (eISBN: 978-83-983017-2-5)

*Praktyczna nauka algorytmów, modelowania i analizy danych w środowisku Jupyter*

> **O zbiorze materiałów**
>
> Prezentowany zbiór zadań został zaprojektowany w myśl koncepcji nauki przez praktykę. Abstrakcyjne pojęcia matematyczne i informatyczne zostały przełożone na realne wyzwania z zakresu medycyny, energetyki, ekologii, rynku nieruchomości i sztucznej inteligencji. Każdemu modułowi roboczemu dla studenta towarzyszy pełne, wzorcowo opracowane rozwiązanie (`_rozwiazane`), stanowiące wsparcie samokontroli i samokształcenia.

## Budowanie książki

Zainstaluj zależności:

```bash
python3 -m pip install -r requirements.txt
```

Następnie zbuduj książkę HTML:

```bash
jupyter-book build .
```

Gotowa książka będzie dostępna w `_build/html/index.html`.
